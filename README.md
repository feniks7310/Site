# СТРОЙМАРКЕТ — сайт-визитка

Современный высокотехнологичный сайт-визитка крупнейшего строительного магазина Сосновоборска.

## Возможности

- 🎨 Тёмный high-tech дизайн с неоновыми акцентами
- ✨ Анимации: прелоадер, частицы, 3D-tilt карточки, бегущая строка, счётчики, reveal при скролле
- 🗺️ Встроенные карты **Яндекс Карты** и **2ГИС** с кнопкой переключения
- 📸 Галерея с лайтбоксом (фото из папки `foto_magazina/`)
- 📱 Полная адаптивность под мобильные устройства
- 🖱️ Кастомный курсор
- 🔝 Кнопка «наверх»

## Запуск

Просто откройте `index.html` в браузере или запустите локальный сервер:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Настройка

### Социальные сети

В файле `index.html` найдите блок `.socials` и замените `href="#"` на реальные ссылки:

- **VK** — ссылка на сообщество ВКонтакте
- **Telegram** — ссылка на Telegram-канал
- **Макс · Авито** — ссылка на профиль/объявления на Авито

### Карты

Координаты магазина заданы в нескольких местах файла `index.html`:

- `56.126389, 93.354167` — координаты (проверьте и при необходимости уточните)
- Яндекс: `https://yandex.ru/map-widget/v1/?ll=...&z=17&mode=whatshere...`
- 2ГИС: `https://widgets.2gis.com/widget?center=...&zoom=17&size=m`

Для точной привязки метки к адресу **г. Сосновоборск, ул. Заводская, 1/7**:
1. Откройте [Яндекс Карты](https://yandex.ru/maps/) и найдите магазин
2. Нажмите «Поделиться» → «Встроить карту» и скопируйте ссылку iframe
3. Замените `iframe.src` в функции `initYandexMap()` в `index.html`

Аналогично для 2ГИС: [2gis.ru](https://2gis.ru) → «Поделиться» → «Встроить карту».
